# Defaced Patcher

A simple **Anti-Smoke DLL Patcher** for **Warzone 1.6**, written in C++ for educational and reverse engineering purposes.

Developed by **defaced**.

## Usage

1. Download or compile `DefacedPatcher.exe`.
2. Drag and drop `client.dll` onto the executable.
3. Review the DLL information displayed in the console.
4. Press `Y` to apply the patch.
5. The patched file will be saved as `client_patched.dll`.

## Compilation

**Requirements:**
- Windows 10/11
- Visual Studio 2022
- C++17 or newer

**Build with Visual Studio:**

1. Open Visual Studio 2022.
2. Create a new **Console App (C++)** project.
3. Add the provided `main.cpp` source code.
4. Set the C++ Language Standard to **ISO C++17**.
5. Select **Release** and **x86**.
6. Go to **Build → Build Solution** (`Ctrl + Shift + B`).

The compiled executable will be available in the project's Release output directory.
